# Boxer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A demo web app "Boxer" (shadow boxing at home) with quiz → plan → simulated paywall → 28-day challenge → working guided workout, to show a business partner.

**Architecture:** Static folder `boxer/` on GitHub Pages. `logic.js` holds pure, DOM-free functions (tested with `node --test`); `fighter.js` draws the neon fighter SVG and its poses; `index.html` holds markup, CSS and the screen/UI code. State in `localStorage` key `boxer.v1`. E2E check with the pre-installed Playwright.

**Tech Stack:** Vanilla HTML/CSS/JS (ES modules), Web Speech API (`speechSynthesis`, `it-IT`), Web Audio API for gong/beep, Screen Wake Lock API when available. No dependencies.

**Spec:** `docs/superpowers/specs/2026-11-28-boxer-design.md`

## Global Constraints

- All UI copy in Italian; name "Boxer"; never the words/brand "BetterMe", never its assets.
- Accent neon orange `#ff7a1a` (glow `#ff9a3c`), background `#07070a`; challenge screen cream `#f3efe6` with dark tiles `#16161a`.
- Prices in one object `PRICES` in `logic.js`: 1 sett. 6,99 € · 4 sett. 15,99 € (da 39,99 €, "più scelto") · 12 sett. 29,99 € (da 79,99 €).
- Paywall countdown 10:00. Checkout shows "Demo — nessun addebito".
- Testimonials/percentages marked `// ESEMPIO` in code.
- Works at 320 px width, no horizontal scroll; installable (apple-mobile-web-app meta like `giro/index.html`, `theme-color #07070a`).
- Not linked from the site homepage.
- Builder's call (deviation from spec's "single index.html"): `logic.js` and `fighter.js` sit beside `index.html` in `boxer/` so logic is testable; still one self-contained folder.

## Review Focus

1. Reload mid-funnel → resumes on the same screen with answers kept (no restart, no blank screen).
2. No Italian voice / speech blocked on iOS until a tap → workout still runs with on-screen text and beeps; speech primed on the "Inizia" tap.
3. Phone screen locking mid-workout → request Wake Lock; timer based on timestamps so a backgrounded tab doesn't drift.
4. Odd numeric inputs (height 0, weight 500, target above current when goal is "dimagrire") → inline validation message, Avanti disabled.
5. Tapping a locked day → shows a "Completa il giorno N prima" toast, not a broken sheet.

### Task 1: Pure logic (`logic.js`)

**Files:**
- Create: `boxer/logic.js`
- Test: `boxer/tests/logic.test.mjs`

**Interfaces:**
- Produces (all exported):
  - `PRICES: {id:'w1'|'w4'|'w12', label:string, price:number, was:number|null, perDay:number, best:boolean}[]`
  - `QUESTIONS: {id:string, type:'choice'|'multi'|'number'|'info', title:string, options?:{v:string,label:string,emoji:string}[], unit?:string, min?:number, max?:number}[]` — ids: `sex, goal, age, body, target_body, experience, fitness, zones, minutes, height, weight, target_weight` plus 2 `info` screens.
  - `validateAnswer(q, value, answers) -> string|null` (Italian error or null)
  - `bmi(heightCm:number, weightKg:number) -> {value:number, label:'Sottopeso'|'Normale'|'Sovrappeso'|'Obesità'}`
  - `projection(answers, start:Date) -> {points:{week:number,kg:number}[], endDate:Date, weeks:number}`
  - `PROGRAM: {day:number, title:string, minutes:number, moves:string[]}[]` (28 entries)
  - `MOVES: {[n:string]: {name:string, say:string, pose:string}}` — 1 jab, 2 diretto, 3 gancio sinistro, 4 gancio destro, 5 montante sinistro, 6 montante destro, S schivata, P passo indietro.
  - `buildWorkout(day:number, level:'principiante'|'intermedio'|'avanzato') -> {phase:'warmup'|'round'|'rest'|'cooldown', seconds:number, label:string, combos:string[][]}[]`
  - `dayStatus(day:number, completed:number[]) -> 'done'|'open'|'locked'`
  - `createTimer(segments, now:()=>number) -> {state(): {index, remaining, phase, combo}, pause(), resume(), skip()}` — remaining computed from timestamps.
